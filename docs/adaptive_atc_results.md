# Итог первого эксперимента с обучаемым ATC

Обучаемый агент реализован, но улучшения настроенного фиксированного ATC на закрытом
тесте не установлено. Результат отрицательный/неопределённый относительно гипотезы
об улучшении и сохранён без последующего подбора на тестовых данных.

## Что было зафиксировано заранее

- Один координатор выбирает k ∈ {0.5, 1, ..., 5} для очередного раунда аукционов.
- Табличный Q-learning, gamma=1; 400 эпизодов на запуск.
- Сетка alpha={0.1, 0.3}; пять независимых seed обучения на каждый вариант.
- 400 train, 50 validation, 150 test сценариев на пяти фиксированных экземплярах.
- Разные seed поступлений и сроков в трёх выборках.
- Главный показатель — total_tardiness / total_processing.
- Фиксированный k, alpha и checkpoint выбирались только по validation.
- Checkpoint 0 (фиксированная политика) включён в процедуру выбора заранее.

## Результаты

Validation выбрала k=2.0 и alpha=0.1.

| Показатель | Настроенный ATC | Процедура выбора Q-политики |
|---|---:|---:|
| Среднее нормированное опоздание | 0.052935 | 0.053836 |
| Среднее суммарное опоздание | 247.326610 | 251.471286 |
| Средний makespan | 1097.918447 | 1098.880651 |

Средний основной показатель вырос на 1.70% относительно baseline.
SD средних по пяти независимым обучениям: 0.001254.
95% bootstrap CI среднего показателя агента: [0.045373, 0.063603].
95% bootstrap CI среднего baseline: [0.044237, 0.063054].
95% bootstrap CI парной разности Q − ATC: [−0.000491, 0.003124].
Двусторонний Wilcoxon по 30 блокам seed: p=0.144172.

Интервал разности включает ноль. При уровне 0.05 нулевая гипотеза Wilcoxon
не отвергается. Это не доказательство эквивалентности методов и не доказательство,
что обучение обязательно ухудшает результат.

Из пяти запусков в трёх validation выбрала checkpoint 0. В двух выбраны
реально обученные таблицы: seed 102 после 300 эпизодов и seed 105 после 400.
Поэтому итоговые средние характеризуют всю процедуру выбора, включая откат
к фиксированной политике, а не пять обязательно адаптивных моделей.

В двух выбранных обученных моделях улучшение на validation не перенеслось
на среднее тестовое качество. Модель seed 102: 0.054870; seed 105: 0.055506.
Обе величины выше фиксированного 0.052935. Новые параметры после просмотра
этих результатов не подбирались.

Все 900 тестовых расписаний прошли проверки. Прошёл 51 автоматический тест,
включая отсутствие обновления политики на test, совпадение постоянного k с
исходным ATC, правильность награды и порядок фиксации параметров до теста.

## Что это означает для работы

Получена воспроизводимая первая реализация обучаемой стратегии и честный baseline.
Сам факт добавления Q-learning не улучшил планирование. Возможные причины —
потеря информации при агрегировании состояния, ограниченный выбор только k,
различия будущей нагрузки в одинаковых наблюдениях и ограниченный бюджет обучения.
Это гипотезы для следующего исследования, а не установленные причины.

При сохранении практического режима основным вариантом остаётся ATC_LOCAL с k=2,
настроенным по validation. Обучаемая политика доступна как экспериментальный вариант.

Для следующей итерации следует сначала исследовать причины на train/validation:
например, информативность признаков и влияние k на выбор победителя.
Повторный подбор по уже открытому test недопустим. Следующее подтверждающее
сравнение требует нового закрытого набора с другими seed (в текущем генераторе
диапазоны заданы в learning_data.SEED_BASE).
